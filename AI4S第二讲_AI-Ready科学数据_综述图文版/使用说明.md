# AI-Ready 科学数据 · 60 页综述图文版

本文件夹是《科学智能原理与实践》第二讲的交互式网页讲义。

## 打开

直接双击 index.html；把整个文件夹保留在一起。图片、交互与讲义说明可离线使用，外部论文和在线数据资源需要联网。压缩包请先完整解压。

## 操作

- ← / → 或底部箭头翻页；Home / End 到首页和末页。
- “目录”或 G：按标题、学科与概念搜索并跳转。
- “讲义与来源”或 N：查看当前页说明、证据边界与来源。
- 点击论文图片：放大、缩小、适合窗口、原始像素，并打开原始文件。
- “深色 / 浅色”或 T：切换背景；首次打开为白底，记住本机选择。
- “全屏”或 F：浏览器支持时进入全屏。
- Esc：关闭图片、讲义或目录。
- 交互按钮改变数据或显示状态；滑块用鼠标或方向键调整。
- 第 39 页分别下载预训练、轨迹后训练与独立评测的合成 JSON 结构。

## 本版内容

以指定综述的数据基础、科学模型、预训练、后训练、评测、数据建设、智能体生态顺序组织。八个学科逐页介绍；知识五层用酶研究贯穿；医学案例比较不同训练原料；四个学科展示数据产品构造；RSI 展示单次修复与可继承方法更新的差别。

完整的逐页讲解和图源见“图文讲义说明.md”。既有定向调研保留在 resources.html、“调研分类总结.md”和“调研资源目录.json”，作为课后检索资料。

## 课堂与自学

60 页兼顾主讲与教材阅读。课堂沿正文主线推进，按学生基础选择展开原图与交互状态；课后可检查样本结构、阅读原文、查数据与工具。页面不标授课时长，不含离堂任务，不包括大数据工程技术课内容。

## 文件

- index.html：课件入口。
- resources.html：分类调研与工具目录。
- assets/：高清预览、原始论文图片与来源清单。
- examples/：三类合成数据结构模板。
- 图文讲义说明.md：60 页讲解及来源。
- 课程教学设计.md：课程主线、学生问题与学习活动。

历史版本保存在 archive/，不会被新课件引用。
