# 课程动态

课程首页导航的“动态”进入 `news.html`。该页展示真实动态的图片、标题、来源、发布日期和摘要，支持关键词搜索；点击进入 `news-article.html?id=...` 阅读全文。动态与博客、书籍分别维护。

`data/news-index.json` 保存目录和双语标题、摘要，正文位于 `data/news/articles/`，原图位于 `data/news/assets/<id>/`。正文保持中文，导航、搜索和阅读操作跟随课程站的中英文及深浅主题偏好。

首次发布内容来自《与大咖对话.docx》，文章日期为 2026-10-16，按作者要求删去文末“课程开源社区”和“课程网站”两个段落，其余保留正文、八幅带图注的图片和三张讲堂海报。海报可左右浏览；所有图片可点击放大，支持上一张、下一张、方向键、Escape 关闭及焦点返回。海报中的讲座日期保留原样。

导入后续动态：

```powershell
python tools/import_news_docx.py "动态.docx" --id article-id --date YYYY-MM-DD
```

导入格式为：第一段标题、第二段来源、第三段课程名称，其后为正文。独立的两位数字与下一段合并成章节标题；紧随单图的“图1”等段落保留为图注；同段多图形成画廊。导入只读取文本及内部图片，原始 Word 文件不进入发布目录。导入后需在目录中添加标题、英文标题、摘要、发布日期和封面，核对原文与图像后发布。

验证：

```powershell
node --test tests/news.test.mjs
python -m unittest discover -s tests -p test_news_import.py
python tools/build_paper_index.py --site
```

## CNCC 2026 报告

《老师汇报.docx》对应 `cncc-2026-haihong-e`，日期为 2026-10-23。保留七张配图、原文及章节结构；去掉正文中重复的标题与末尾署名，二级小标题使用 `heading` 的 `level: 3`，二维码图片使用 `compact: true`。导入后的章节与视频位置需保留这些编辑处理，避免直接重新导入覆盖。

“报告回看”段后使用 `video` 内容块，`src` 为作者提供的阿里云 OSS HTTPS MP4 直链，`poster` 使用报告视频开头的 PPT 标题页（`cncc-report-ppt-poster.jpg`），`caption` 为报告说明。播放器采用浏览器原生控件，支持手机内联播放、进度拖动及全屏，加载时只预取元数据，不自动播放；视频文件不进入 Git 仓库。对象存储链接需保持有效并支持字节范围请求。

浏览器回归检查：在已安装 Playwright 与 Chrome 的环境中，先构建站点，再运行 `node tools/check_news_ui.cjs`。检查两篇动态、手机布局、深浅主题、中英文，以及真实视频加载、播放和拖动进度；因此需要连接对象存储。设置 `NEWS_URL` 可以检查已部署站点。

## 首页最新动态

首页顶部自动读取同一份 `data/news-index.json`，按 `date` 选择最新文章，展示日期、双语标题与摘要，并链接到该篇详情。新增动态只需更新动态目录及正文，无需另改首页。页面打开时、回到当前标签页时，以及前台每 60 秒重新检查目录；因此新目录部署生效后，已打开的首页也会自动替换。短暂网络故障保留上次成功显示的内容；空目录则隐藏提要。

首页浏览器检查：构建站点后运行 `node tools/check_home_news_ui.cjs`，验证最新提要、详情跳转、中英文、主题和手机布局，并模拟新动态发布、连接故障及空目录。可通过 `NEWS_URL` 指向线上站点。

CNCC 文章开头照片使用作者另行提供的高清原图 `cncc-report-photo.jpg`（4160 × 1920），不再使用 Word 中的低清照片。其余六张图保持 Word 原图。两张二维码的 `caption` 分别为“书籍在线阅读二维码”和“课程主页二维码”，同时用于正文图注、放大窗口说明及图片辅助文字；重新导入文档时需保留这些修正。

动态列表使用单独的 `cncc-report-cover.webp`（960 × 443），由高清原图以 Lanczos 重采样、WebP 质量 90 生成，避免浏览器直接将 4160 像素宽图片缩到卡片尺寸产生文字锯齿与断线。文章内照片和点击放大继续使用未改动的高清原图；视频封面独立使用报告视频开头的 PPT 标题页。
