# 论文采集与审核监控：设计与实施计划

目标：以来源和年份为单位，汇总采集快照、刊会结论、逐篇精筛和阶段反馈，提供总体与负责人视图和行动清单。保留未知状态及原始证据，禁止把初筛、采集完成解释为精筛完成或官网查全。

数据源：公开仓库 BUPT-AI4S/ai4s-crawler 的 `metadata/<year>/snapshot.json`、`reviews/venue-review.csv`、`reviews/<year>/*.json`，并识别部分现有 coverage 文件和新增 `reviews/<year>/feedback/*.json`。各来源的论文用 `(venue, id)` 去重；不同来源不合并。反馈必须匹配快照才能参与当前汇总。所有展示数据均为公开数据，链接固定到输入仓库提交。

1. 汇总脚本：把不同来源标准化为静态 JSON，记录提交、快照时间、审核文件与证据；未知数值保持 null。验证快照不一致、未知总量、判定计数。
2. Pages：提供年份、负责人、来源和状态筛选，展示各项问题及可下载的按筛选范围行动清单。分别检查桌面、手机、空结果和加载错误。
3. 工作流和反馈说明：Pages 构建时检出爬虫仓库并生成快照，周期调度以发现外仓推送；文档说明时效、反馈路径和总数口径。验证实际数据生成与部署构建。
