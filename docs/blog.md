# 公众号文章页面

`blog.html` 展示公众号文章卡片，以十三个紧凑文件夹口袋作为分类入口，保留“全部文章”。桌面分类七列两行，较窄屏幕五列，手机三列。页面整体滚动，标题和分类随页面移出视野；顶部固定导航的“分类”按钮可随时打开分类弹层，显示各类文章数量，支持点击选择、关闭按钮和 Escape 关闭。文章卡片桌面三列、平板两列、手机单列。列表页和阅读页沿用课程介绍页的背景、渐变与深浅主题配色。

分类由目录中的 `collection` 指定：`reviews`（综述，前四篇，`seriesPart` 为1至4）、`agents`（科学智能体）、`foundation`（科学基础模型）、`knowledge`（科学知识建模）、`data`（科学数据）。口袋和文章颜色按分类保持一致，中英文和深色模式均适配。分类保存为 `?category=reviews` 等 URL 参数，从全文返回会恢复分类并定位原文章。既有 `categories` 保留为文章研究主题元数据，页面归类以 `collection` 为准。

`evaluation`（评测）已收录 HLE 解读，保留 `labs`（自主实验室），以及 `math-physics`、`life`、`matter`、`earth`、`information`、`social` 六个 AI4 学科方向。空分类保留可点击入口，以虚线区分，进入后显示待补充状态，不添加模拟文章。后续只需给新文章设置相应 `collection`，该分类即自动显示文章。

前十篇文章保留既定顺序：科学大模型的起点、科学大模型的能力从何而来、科学大模型的高分、科研智能体走向发现、Agentic Science、科学基础模型、科学知识建模、S1-Omni、BioMatrix、LOGOS。新增五篇：科学基础模型的预训练（科学基础模型）、科学数据如何进入 AI4S 模型（科学数据）、多智能体如何把临床数据转化为研发线索、多智能体如何提出并检验治疗假设、科学智能体的 Harness 如何支撑科研任务执行（后三篇归入科学智能体）。正文、标题层级、配图、图注与表格均来自提供的 Word 原稿。卡片不把关联论文年份显示成公众号发布日期。

第十六篇为 HLE：常用试卷接近满分之后，怎样测量大模型的能力边界？归入评测分类（`evaluation`），正文与五张原始配图来自 `HLE.docx`，包含作为图片保留的模型评测结果表及图注。论文、仓库链接可从卡片和阅读页访问。

目录与摘要位于 `data/blog-index.json` 的 `articles` 中。正文位于 `data/blog/articles/<id>.json`，图片位于 `data/blog/assets/<id>/`。`blog-article.html?id=<id>` 按一级正文标题（数据中的 level 2）分章，每次只渲染当前一章；开篇文字单列“引言”，子标题、配图和表格随所属章节展示。底部提供上一章、下一章及返回列表，首尾禁用越界按钮。桌面目录位于左侧，手机目录可展开。章节由 URL 的 `#intro`、`#part-N` 定位，支持刷新、前进和后退，保留旧标题锚点（含子标题）的编号。返回列表链接恢复分类并定位至原卡片。正文中的原始论文链接仍然保留。

博客列表和阅读页均提供中英文切换，沿用主页的 `ai4s-lang` 浏览器偏好，也支持 `?lang=en`。英文范围包括界面、分类、文章标题和卡片摘要；正文、图片及目录中的原文标题保留中文。目录中的 `titleEn`、`summaryEn` 保存对应英文文案，维护文章时需一并更新。

新增文章时可运行 `python tools/import_blog_docx.py "文章.docx" --id article-id`，然后在目录中添加标题、摘要、分类和 `order`。同一 ID 会覆盖原文章，导入后请核对内容和图片。每张图片只将首个紧随其后的图注段落作为图注，后续读图说明保留为正文，避免覆盖来源。原始 Word 文件无需上传到网站。

通过 `python -m http.server 8081 --bind 127.0.0.1` 预览，打开 `http://127.0.0.1:8081/blog.html`。使用纯静态资源，现有 Pages 打包会自动包含新页面、正文和图片。博客内容完整性及分章检查：`node --test tests/blog.test.mjs tests/blog-chapters.test.mjs`；文档导入检查：`python -m unittest discover -s tests -p test_blog_import.py`。
