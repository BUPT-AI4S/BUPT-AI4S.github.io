# 论文细粒度标签

细粒度标签的中英文显示名及同义词保存在 `data/keyword-tag-vocabulary.json`，由构建器加载，与 `data/paper-tags.yml` 中原有的六个标签合并。前端继续使用已有语言按钮：中文模式读取 `nameZh`，英文模式读取 `nameEn`；页面默认中文，保留用户主动选择的语言。

本轮将 3,433 个原标签整理为 3,080 个标签，覆盖 4,513 篇论文。翻译由 Terra 初译并复核，合并缩写、单复数和同义表达；扩散模型、扩散桥、扩散过程等不同概念分别保留。原始论文 `keywords` 不变，合并前的标签 ID 和英文名称保留在 `aliases`，旧筛选链接仍可解析。

新增元数据关键词时，应先为词表补充中英文名称或添加到已有标签的 `aliases`。存在词表时，构建器会拒绝未翻译的新关键词，避免中文页面再次出现未处理的英文标签。不要把仅仅相关的研究概念当作同义词合并。
